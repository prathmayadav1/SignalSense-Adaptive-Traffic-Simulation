# SignalSense – Adaptive Traffic Signal Simulation

SignalSense is a Python-based adaptive traffic signal simulation project developed using Pygame.

## Features
- Simulates a four-way road intersection.
- Generates vehicles automatically.
- Adjusts traffic signal timing based on vehicle queues.
- Displays Red, Yellow, and Green signals.
- Visualizes vehicle movement.

## Technologies Used
- Python
- Pygame CE

## How to Run
1. Install Python.
2. Install Pygame CE using:
   `pip install pygame-ce`
3. Run the project:
   `python signalsense.py`
